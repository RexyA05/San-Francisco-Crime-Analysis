# 🕵️ San Francisco Crime Analysis

A Google Colab notebook for analyzing crime data from San Francisco using Python. This notebook performs data loading, preprocessing, exploratory data analysis (EDA), and visualization to uncover patterns and trends in crime incidents.

---
## 📖 Overview

This notebook includes:

- 📂 Loading the San Francisco crime dataset
- 🧹 Data cleaning and preprocessing
- 📊 Exploratory Data Analysis (EDA)
- 📈 Visualizations of crime trends
- 📍 Analysis based on crime categories, time, and location
- 💡 Key insights derived from the dataset

---

## 📓 Notebook

The complete analysis is contained in a single notebook:

- **`SF_Crime_Analysis.ipynb`**

Open it directly in **Google Colab** or **Jupyter Notebook**.

---
