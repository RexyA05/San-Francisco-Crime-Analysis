# 🕵️ San Francisco Crime Analysis

A data analysis project that explores crime incidents in San Francisco using Python and Google Colab. The project focuses on cleaning, analyzing, and visualizing crime data to identify patterns, trends, and insights.

---

## 📌 Project Overview

This project aims to:

- Analyze crime records from San Francisco.
- Perform data cleaning and preprocessing.
- Generate meaningful visualizations.
- Identify crime trends based on time, location, and category.
- Build a foundation for future predictive analytics and machine learning models.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/RexyA05/San-Francisco-Crime-Analysis.git
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the notebook

Open:

```
SF_Crime_Analysis.ipynb
```

using Google Colab or Jupyter Notebook.
